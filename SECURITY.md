# Security policy

LocalPay is a local testing tool. It must never touch real money or real keys, never
listen on a public network unless forced, and never be mistakable for a real payment page.
Reports about any of those are in scope.

## Reporting a vulnerability

Use GitHub private vulnerability reporting on this repository (Security tab →
"Report a vulnerability"). Please do not open a public issue.

- Acknowledgement within 72 hours.
- Coordinated disclosure within 90 days, sooner if a fix ships earlier.

## Supported versions

Only the latest 0.x release receives fixes until v1.0.
