# Governance

- **Decision making.** Maintainer-led (BDFL) until there are 3 or more regular
  maintainers; then documented lazy consensus.
- **Big changes.** Start an RFC as a GitHub Discussion. Accepted decisions are
  recorded as an ADR in docs/adr/ and one line in .claude/memory/decisions.md.
- **Contributions.** Developer Certificate of Origin (`git commit -s`); no CLA.
- **Versioning.** SemVer. 0.x releases may break, with notice in CHANGELOG.md.
- **Code of conduct.** Contributor Covenant 2.1 (CODE_OF_CONDUCT.md).
